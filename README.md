### Overview
Lab-1 focuses on requirements engineering and system design using use-case modeling and software requirements specifications. This lab includes comprehensive documentation of system requirements, use-case flows, and visual system architecture diagrams.

- **Use-Case Flow Specification**: Complete use-case diagrams and flows defining system interactions and user scenarios
